# Personal Expense Tracker

A full-stack web application to manage personal income and expenses.

## Features

- User Registration and Login
- Add Income and Expense
- Edit and Delete Transactions
- Filter by Type, Category and Date
- Total Income, Expenses and Balance
- Recent Transactions
- User-specific Transaction Data
- Logout and Login Protection
- MySQL Database Persistence
- Responsive Design

## Technologies Used

**Frontend:** HTML, CSS, JavaScript, Bootstrap

**Backend:** Java, Spring Boot, Spring Security, REST API

**Database:** MySQL

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database in `application.properties`.
4. Run the Spring Boot application.
5. Open the application in a browser.

## Project Structure

- `src/main/java` — Backend Java code
- `src/main/resources/static` — Frontend files
- `application.properties` — Database configuration
- `pom.xml` — Maven dependencies
